1.2 Probleme principal visible : le Dashboard
Le dashboard affiche 4 cartes avec value: "—" en dur dans le code (dashboard/page.tsx:7-12). Ce sont des constantes statiques, pas des variables. Aucun appel API n'est fait. La raison est simple :

Aucun endpoint d'agregation n'existe cote backend
Aucun useQuery n'est present dans la page dashboard
Les valeurs sont un tableau JavaScript hardcode
La section "Activite recente" est egalement un placeholder statique.
